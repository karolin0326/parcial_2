# Tabla de Interacciones

| Entidad Externa | Información / Acción que envía | Respuesta que recibe del sistema |
|---|---|---|
| Usuario Contable | Registro de facturas, consulta de facturas, validación de información y registro de pagos | Confirmación de registros, alertas de inconsistencias, resultados del análisis IA y reportes de monitoreo |
| Administrador del Sistema | Configuración de parámetros, gestión de usuarios, administración de permisos y ajustes del sistema | Confirmación de cambios, reportes de actividad y estado general del sistema |
| Sistema de Facturación | Datos de facturas generadas y actualizaciones de facturación | Confirmación de monitoreo, validación y procesamiento de facturas |
| Motor de Inteligencia Artificial | Resultados del análisis de datos, detección de anomalías y clasificación de irregularidades | Datos de facturación para análisis y retroalimentación del sistema |
| Sistema ERP Contable | Información financiera, registros contables y estados de pagos | Actualización de información contable y validaciones financieras |
| DIAN / Entidad Fiscal | Validación normativa de facturas electrónicas y reglas fiscales | Confirmación de cumplimiento o notificación de errores tributarios |

---

# Descripción General

La tabla de interacciones representa el flujo de comunicación entre las entidades externas y el Sistema de Monitoreo Inteligente de Facturación con IA.

Cada entidad intercambia información específica con el sistema para permitir:
- el registro y validación de facturas,
- el análisis automático mediante inteligencia artificial,
- la integración con sistemas contables,
- el cumplimiento de normativas fiscales,
- y la generación de alertas y reportes.

Estas interacciones garantizan el correcto funcionamiento del sistema y permiten mantener la integridad, trazabilidad y supervisión de los procesos de facturación.
