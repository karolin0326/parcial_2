# Tabla de Contexto

| Entidad Externa | Tipo | Descripción |
|---|---|---|
| Usuarios Contables | Usuario | Personal del área contable encargado de generar, revisar y validar facturas dentro del sistema. |
| Administrador del Sistema | Usuario | Responsable de configurar el sistema, gestionar usuarios y supervisar el funcionamiento de la plataforma. |
| Sistema de Facturación | Sistema Externo | Plataforma donde se generan las facturas que serán monitoreadas por el sistema de IA. |
| Motor de Inteligencia Artificial | Sistema Externo | Módulo que analiza los datos de facturación para detectar errores, anomalías o inconsistencias. |
| Sistema ERP Contable | Sistema Superior | Sistema empresarial donde se registran y almacenan los datos financieros y contables de la organización. |
| Entidad Fiscal / DIAN | Sistema Regulador | Plataforma gubernamental encargada de validar y recibir la información de facturación electrónica. |

---

## Descripción General

La tabla de contexto identifica las entidades externas que interactúan con el Sistema de Monitoreo Inteligente de Facturación Contable con IA.  
Cada entidad cumple un rol específico dentro del flujo de información del sistema, permitiendo la gestión, análisis, validación y supervisión de los procesos de facturación.

Estas entidades intercambian información con el sistema central para garantizar:
- El registro y control de facturas.
- La detección de anomalías mediante inteligencia artificial.
- La validación normativa ante la DIAN.
- La integración con sistemas contables empresariales.
- La generación de reportes y auditorías.
